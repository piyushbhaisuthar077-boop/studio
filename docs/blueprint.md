## Style Guidelines:

- Primary color: Dark Blue (#1E3A8A) to inspire confidence and represent expertise.
- Background color: Light gray (#F5F5F5), near white, for a clean and professional feel.
- Accent color: Lighter Blue (#3B82F6) to provide emphasis to key actions without disrupting visual harmony.
- Headline font: 'Poppins' (sans-serif) for a geometric, modern, and professional look.
- Body font: 'PT Sans' (sans-serif) for clear and accessible reading in paragraphs.
- Use flat, modern icons to represent accounting services and improve user understanding.
- Maintain a clean and organized single-page layout with clear section dividers for easy navigation.
